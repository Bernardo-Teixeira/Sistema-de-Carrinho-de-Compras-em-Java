# Sistema-de-Carrinho-de-Compras-em-Java
Desenvolvi um sistema de carrinho de compras em Java com cadastro, listagem, ordenação e remoção de produtos. Apliquei orientação a objetos, encapsulamento e estruturas como ArrayList, Comparator e Iterator, permitindo ordenar produtos por nome e preço em ordem crescente e decrescente, além de realizar remoções seguras durante a navegação da lista.
